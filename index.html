Conexión con OBS

Opción A (recomendada, sin internet): panel dentro de OBS. Menú Docks → Docks de navegador personalizados, agregá este panel con su URL. Como el dock y la fuente de navegador comparten el mismo perfil de OBS, se sincronizan solos.

Opción B (por internet): controlá desde cualquier dispositivo. Ambos lados usan el mismo código de sala (relé gratuito ntfy.sh; quien conozca el código puede mandar zócalos, así que no lo compartas).
